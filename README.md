\# Ambulance Tracking System



A Django-based web application designed to manage ambulance information, ambulance bookings, and booking history through a simple web interface.



\## 📌 Project Overview



The Ambulance Tracking System helps users book ambulances during emergencies and allows administrators to manage ambulance details and bookings efficiently.



\## ✨ Features



\- User login

\- Ambulance registration

\- View ambulance list

\- Emergency ambulance booking

\- Ambulance availability management

\- Booking history

\- Dashboard with ambulance statistics

\- Django Admin panel

\- Database-backed booking management



\## 🛠️ Technologies Used



\- Python

\- Django

\- HTML

\- CSS

\- SQLite

\- Git

\- GitHub
